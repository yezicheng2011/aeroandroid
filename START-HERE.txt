M5 / Apple Silicon · Android Subsystem 0.2.0
Pure AOSP Android 16 + Magisk + microG

1. Unzip M5-Android16-0.2.0-AOSP-microG.zip. The source code and all offline runtime dependencies are bundled together:

   M5-Android16-0.2.0-AOSP-microG/
     Build.command
     AndroidSubsystem/
       Build.command
       Install.command
       Migrate-to-AOSP.command
     runtime-cache/
       android16-macos/
       mac-tools/
       provision/

2. You need macOS 14 or later, the Xcode Command Line Tools, and at least 20 GB of free space.
   If the developer tools are not installed, run first: xcode-select --install
3. Double-click the top-level Build.command. It prepares the offline environment, builds the native app,
   configures Magisk, microG and the signature-compatibility module, and installs to ~/Applications/Android Subsystem.app.
   You will need to read and accept the Android SDK license. No separate Python, Java or Homebrew install is needed.
4. For an existing installation, it first quits the manager app, stops the VM using the backend that matches the
   current configuration, and then backs up the configuration. Existing memory settings such as 6 GB are kept.
   AOSP uses a separate Android data environment, so apps need to be reinstalled; old user data is kept as an
   offline backup. The old Google APIs system image is deleted only after the new environment is configured successfully.
5. After installing, open "Self-Check" in microG settings, then verify the apps you actually need.
   By default it does not sign in to Google or enable device registration or push messaging. See docs/MICROG.md.

This package does not include GApps, the Google Play Store, Chrome or the proprietary DroidGuard.
microG is an open-source compatibility implementation; a successful install does not guarantee that every GMS API or Play Integrity works.
APK build, signing and controlled testing have passed; on-device acceptance of the new AOSP/microG build on an M5 is still pending.
Commercial distribution must still comply with the SDK and each open-source component's license; see README.md for details.

If you only downloaded AndroidSubsystem-source.zip, provide a runtime-cache that matches runtime-lock.json;
it can sit next to the source folder or inside it. The full single package needs no extra downloads.
The log path is shown whether the build succeeds or fails; press Enter in Terminal to close.
Logs are in ~/Library/Application Support/AndroidSubsystem/logs/.
If you run into problems, please provide the install log; scripts/collect-diagnostics.py collects diagnostics and never uploads anything automatically.
