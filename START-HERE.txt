aeroandroid

Install from the official macOS package. You do not package a release yourself.
Download it from the latest GitHub release or https://aeroandroid.com/releases.html
(the build produces aeroandroid-1.2.0-macOS-universal.pkg).

1. If you have not already, install the Xcode Command Line Tools: xcode-select --install
2. Open the .pkg. macOS says it is unsafe, or that it cannot verify the developer
   (unidentified developer). That warning is expected. The package is ad-hoc signed
   and is not notarized.
3. Allow it in System Settings → Privacy & Security, then open the package again.
4. Install it. The installer puts Android Subsystem in /Applications and asks for
   an administrator password.
5. Open /Applications/Android Subsystem.app. If macOS blocks the app the same way,
   allow it in System Settings → Privacy & Security.
6. The app downloads Android and shows a progress bar. Accept the Android SDK license
   on that screen. The download source is chosen from your public location: mainland
   China uses a mirror; other locations, and a failed lookup, use the official source.

The Android runtime (about 1.8 GB) is downloaded on your Mac and checked with SHA-256.
The Android SDK license does not allow that runtime to be redistributed inside the package.

Requires a Mac (Apple Silicon, or Intel from 2018 on), macOS 14 or later, the Xcode
Command Line Tools, about 20 GB of free disk, and a network connection.

The default install is Android 17, AOSP only: no Magisk, microG or pre-installed apps.
Android 17 is the only Android version. An older installation keeps its apps and data
as a backup when upgraded. New installs use automatic memory budgeting at each start;
choose Automatic or Manual in Settings. Running VMs do not resize live.
  AOSP only (default): ./build.sh
  Explicit AOSP only:  ./build.sh --pure
  Optional full edition: ./build.sh --with-gpl (downloads GPL extensions)
The external Android runtime and JDK retain their own licenses, including GPL parts.
See docs/LICENSING.md; AOSP-only does not mean a GPL-free runtime.

Building from a git checkout uses the same ./build.sh. See README.md and BUILD.md.
Packaging on a Mac: ./scripts/build-mac.sh, then ./scripts/package-pkg.sh.

Logs: ~/Library/Application Support/AndroidSubsystem/logs/
If something fails, scripts/collect-diagnostics.py collects diagnostics and does not upload them.
