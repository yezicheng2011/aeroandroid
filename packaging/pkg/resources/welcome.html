Install aeroandroid @VERSION@

This installs Android Subsystem into /Applications. The app then downloads Android on its first launch and shows a progress bar. The Android runtime is not inside this package.

macOS reports this package as unidentified or unsafe because it is not notarized. That check is expected. If the package was blocked, allow it in System Settings → Privacy & Security, then come back and continue. The installer asks for an administrator password so it can write to /Applications.

Requirements: a Mac with Apple Silicon or a 2018-or-newer Intel Mac, macOS 14 or later, the Xcode Command Line Tools (xcode-select --install), about 20 GB free, and a network connection.
